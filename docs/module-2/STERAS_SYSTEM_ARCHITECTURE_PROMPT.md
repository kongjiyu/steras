# Image Generation Prompt

**Mode:** Built-in `image_gen`

**Use case:** `infographic-diagram`

Create a polished landscape architecture diagram titled **“STERAS SYSTEM
ARCHITECTURE”** with the subtitle **“Serverless Modular Monolith • Layered +
Event-Driven”**. Present it as a C4-inspired container and component view on a
clean white background, using crisp vector-like boxes, readable sans-serif
labels, orthogonal arrows, and generous whitespace.

Show three users—Event Organiser, Authority Officer, and Public Viewer—above a
“STERAS — Firebase Platform” boundary. Inside the boundary, show four horizontal
layers:

1. **Presentation Layer:** Firebase Hosting; React SPA, Vite, and Tailwind; M1
   Events, M2 Risk & Resources, M3 Approval, M4 Incidents, and M5 Analytics.
2. **Application Layer:** Firebase Auth & Security Rules, Callable APIs,
   Firestore Triggers, and Integration Adapters split into Context Adapter and
   MiniMax Assessment Adapter.
3. **Domain Layer:** M1 Event Lifecycle, M2 AI Input Validation, M2
   Deterministic Risk Calculation, M2 Resource Rules, M3 Admin Manual Review and
   Human Decision, M4 Incident Workflow, and read-only M5 Aggregation. Clearly
   state **“AI proposes inputs • M2 validates & calculates • Admin reviews”**
   and **“AI never approves”**.
4. **Data Layer:** Cloud Firestore, Cloud Storage, and Audit & Version History.

Outside the boundary, group OpenWeather, Holiday Dataset, and WHO/PDRM/BOMBA
guidance as Context Sources. Put MiniMax M3 in a separate Structured AI
Assessment group and label it **“hazards + likelihood/severity proposals”**.
Context Sources connect only through the Context Adapter. MiniMax connects only
through the MiniMax Assessment Adapter using validated structured JSON. Show
user-to-SPA flow, callable and Firestore-triggered orchestration,
domain persistence, verified M4 history entering future M2 assessments, and the
MiniMax proposal → M2 validation/hard rules → deterministic risk calculation →
resource rules → human M3 decision sequence. On MiniMax timeout, unavailability,
or invalid output, show M2 creating a review-required handoff to M3, where an
Admin performs the authorised manual-review process. M2 must not be shown as
performing manual review.

Add a Local Quality Gate with Firebase Emulator Suite, Vitest, and Rules Tests.
Add badges for Separation of Concerns, High Cohesion, Low Coupling,
Encapsulation, Typed Contracts, and Fail-Safe AI.

Use civic blue, navy, violet, green, amber, and pale gray with accessible
contrast. Do not add cloud server racks, 3D effects, gradients, decorative clip
art, logos, watermarks, invented technologies, extra modules, or duplicate
labels.

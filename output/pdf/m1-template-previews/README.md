# M1 Template Preview PDFs

These PDFs are browser-preview derivatives of the canonical Word templates in `docs/templates/m1/`. They are emitted by the Vite build under `/templates/m1/previews/`; the original DOCX files remain the editable download source.

The Cultural, Heritage and Festival Event - Indoor preview intentionally omits the source DOCX's known blank final page. No content page was removed.

`SHA256SUMS` records the reviewed preview artifacts. Recreate and visually inspect every page whenever a source template changes.
